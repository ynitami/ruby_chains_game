## レシーバーカード

1.  `" Hello World "` (String)
2.  `"1,2,3,4,5"` (String)
3.  `"Ruby_Chains"` (String)
4.  `"no Ruby, no life"` (String)
5.  `[10, nil, "bug", 20]` (Array)
6.  `["Method", "Class", "Object", "Method"]` (Array)
7.  `[1, [2, 3], 4]` (Array)
8.  `{id: 19, year: 2025, name: "Takumi's Tech Book"}` (Hash)
9.  `{1 => "Integer", 1.0 => "Float", "key" => "String"}` (Hash)
10. `{ false => "Game Over", :score => [10, 5, -2], 100 => :bonus }` (Hash)

## 要求カード

1.  A: `全て大文字`の`String`にせよ。 / B: `全ての要素がInteger`である`Array`にせよ。
2.  A: `10以上`の`Integer`にせよ。 / B: `キー (key) にString`を**含む** `Hash`にせよ。
3.  A: `10文字以上`の`String`にせよ。 / B: `要素数が5個以上`の`Array`にせよ。
4.  A: `0 (ゼロ)`の`Integer`にせよ。 / B: `キー (key) がInteger`である`Hash`にせよ。
5.  A: `重複する要素を**含む**` `Array`にせよ。 / B: `数字 (0-9)`を**含む** `String`にせよ。
6.  A: `値 (value) にInteger`を**含む** `Hash`にせよ。 / B: `3桁以上` (100 以上) の`Integer`にせよ。
7.  A: `空 (Empty)`の`Array`にせよ。 / B: `空 (Empty)`の`String`にせよ。
8.  A: `要素数が3以下`の`Array`にせよ。 / B: `値 (value) がArray`である`Hash`にせよ。
9.  A: `Hash`にせよ。 / B: `1文字`の`String`にせよ。
10. A: `全ての要素が同じ` `Array`にせよ。 / B: `キーと値が同じ` `Hash`にせよ。
